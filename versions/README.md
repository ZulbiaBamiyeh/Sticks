# Saved versions

Frozen copies of Home Turf, kept so later experiments can always be compared
against a known-good game. Each file is complete on its own: open it in a browser.

| File | What it is |
| --- | --- |
| `home-turf-v2-rivals.html` | Six weapons, four skills (Blink, Dark Sight, Parry, Hook), the eight-rival ladder with its scouting page, before any roguelike systems. Same as commit `6cd817a`. |
| `home-turf-v3-acrobatics.html` | Adds acrobatics (roll, wall jump, wall run, air flip), blade exchanges, pad plays, shooters that kite, and random Wildfrost music. The last version before statuses, trinkets and mobs. Same as commit `020d500`. |

The live game is always `../index.html`. Don't edit these files; save a new copy instead.
